When you want to add more images, just follow these two simple steps:

Add your new image files to the correct folder (e.g., put hard_sweep_idx291.png into public/SweepImages/Hard_Sweep_Images).

Open app/play/page.tsx and update the count in the IMAGE_CONFIG object.

Images are served directly from this repo via GitHub Pages (public/SweepImages/...) — there is no external image host to configure.
